# errors

Corrections register. Add new rows at the end of each table with the next id (`templates/error-entry.md`). Never delete a row: mark it `resolved` with a note and a date.

- **E** - a wrong statement in a source or an older page
- **B** - a bug in code or a pipeline
- **T** - a tool or environment note that cost time
