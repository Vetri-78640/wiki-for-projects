# decisions

One record per significant decision: a choice that is costly to reverse, that others will ask "why?" about, or that constrains later work. Template: `templates/decision.md` (Nygard's format with the option comparison from MADR).

- File names: `NNNN-short-title.md`, numbered in order, never reused.
- Status: `proposed`, `accepted`, `rejected`, `superseded by [[NNNN-...]]`.
- Write the record before acting. Once accepted, do not rewrite the decision; write a new record that supersedes it and update the old status line.
- Keep the evidence: what was known at the time, and where it came from.
